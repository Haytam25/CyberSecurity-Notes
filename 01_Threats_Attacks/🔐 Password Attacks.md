## 🔍 Definition
> Attacks that attempt to obtain or crack user passwords to gain unauthorized access.

## 🧰 Common Types

- **Brute Force**  
  Tries all possible combinations of characters.

- **Dictionary Attack**  
  Uses a precompiled list of likely passwords.

- **Hybrid Attack**  
  Combines dictionary words with mutations (e.g., "Password1").

- **Credential Stuffing**  
  Uses breached credentials from other websites.

- **Keylogging**  
  Malware that records keystrokes to capture credentials.

- **Rainbow Table Attack**  
  Uses precomputed hashes to reverse password hashes.

- **Shoulder Surfing**  
  Physically observing a user enter their password.

## 🛡️ Mitigations

- Strong password policies (length, complexity)
- Account lockout policies
- Multi-Factor Authentication (MFA)
- Use of password managers
- Salting + hashing passwords securely
- CAPTCHA and rate limiting on login attempts

# 🧱 Physical Security Controls

## 🧍 Human-focused Controls

- **Security Guards**  
  Provide live monitoring and access control.

- **Escort Visitors**  
  Ensure non-employees are accompanied in sensitive areas.

- **Training & Awareness**  
  Physical security awareness (e.g., badge policy, tailgating risks).

## 🔒 Barriers & Devices

- **Mantraps**  
  Double-door systems that prevent tailgating.

- **Biometrics**  
  Fingerprints, facial recognition, etc.

- **Smart Cards/Badges**  
  Used for authentication + physical access.

- **Video Surveillance (CCTV)**  
  Monitors and records activity.

- **Fences, Gates, Turnstiles**  
  Basic perimeter controls.

- **Locks**  
  Mechanical, electronic, or biometric locks.

- **Motion Sensors / Alarms**  
  Detect unauthorized movement or access.

## 🛠️ Environmental Controls

- **Fire Suppression** (e.g., CO₂, FM-200)
- **HVAC**: Maintain appropriate temperature/humidity for systems.
- **Shielding**: Prevents EM interference or data leakage (e.g., Faraday cages).
- **Hot/Cold Aisles**: Optimize airflow in server rooms.
