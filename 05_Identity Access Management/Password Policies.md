## Password Requirements
- Minimum length: 8+ characters
- Complexity: uppercase, lowercase, number, special character
- Expiration: e.g. every 60–90 days
- Password history: disallow reuse of last N passwords
- Lockout policy:
  - Lock after X failed attempts
  - Lockout duration or manual unlock

## Best Practices
- Use password managers
- Avoid:
  - Dictionary words
  - Personal info (birthdays, names)
  - Reuse across multiple sites
