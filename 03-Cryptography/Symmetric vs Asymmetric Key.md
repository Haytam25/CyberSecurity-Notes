#### 🔐 Symmetric vs Asymmetric Encryption

| Aspect             | Symmetric                   | Asymmetric                        |
| ------------------ | --------------------------- | --------------------------------- |
| Key Used           | One key (shared)            | Two keys (public/private)         |
| Speed              | Faster                      | Slower                            |
| Use Cases          | Encrypting large data (AES) | Secure key exchange, digital sigs |
| Example Algorithms | AES, DES, RC4, 3DES         | RSA, ECC                          |
