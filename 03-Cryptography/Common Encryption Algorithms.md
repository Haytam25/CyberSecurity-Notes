## **Symmetric**:

- AES (Advanced Encryption Standard) – 🔒 Strong and fast
    
- DES / 3DES – Older, less secure
    
- RC4 – Deprecated (used in WEP)
    

## **Asymmetric**:

- RSA – Widely used, key exchange, digital signatures
    
- ECC – Shorter key, faster than RSA for same security
    

## **Hashing**:

- MD5 – 🔴 Broken
    
- SHA-1 – 🔴 Broken
    
- SHA-2 – ✅ Secure (includes SHA-256, SHA-512)
    
- SHA-3 – ✅ Alternative standard
    
- HMAC – Hash-based Message Authentication Code (adds key to hashing)
