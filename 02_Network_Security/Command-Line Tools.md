| Tool                                       | Use Case                       | Example                |
| ------------------------------------------ | ------------------------------ | ---------------------- |
| `ping`                                     | Test connectivity              | `ping 8.8.8.8`         |
| `tracert` (Windows) / `traceroute` (Linux) | Show path to destination       | `tracert google.com`   |
| `nslookup`                                 | DNS name resolution            | `nslookup openai.com`  |
| `ipconfig` / `ifconfig`                    | Network interface info         | `ipconfig /all`        |
| `netstat`                                  | Show network connections       | `netstat -an`          |
| `netcat (nc)`                              | Port scanning, banner grabbing | `nc -v google.com 80`  |
| `tcpdump`                                  | Capture network traffic        | `tcpdump -i eth0`      |
| `nmap`                                     | Network scanning               | `nmap -sV 192.168.1.1` |
| `whois`                                    | Domain info                    | `whois example.com`    |
| `dig`                                      | DNS lookup (Linux/Unix)        | `dig openai.com`       |
