## 🔍 Definition
Network segmentation is the practice of splitting a computer network into smaller subnetworks (segments) to improve security and performance.

## 🎯 Purpose
- Limit the spread of malware
- Isolate sensitive systems
- Reduce congestion
- Enforce access controls

## 🧱 Common Methods
- physical (dividing them such there is no physical connection{air gap between them} )
- logical or virtual( VLANs (Virtual LANs) , Subnets , Firewall rules)

## ✅ Benefits
- Improved security
- Easier monitoring and containment
- Better performance

## 📌 Example
| Segment  | Devices Included             |
| -------- | ---------------------------- |
| HR       | HR workstations, servers     |
| Public   | Guest Wi-Fi, web server      |
| Internal | File servers, internal tools |
