# Zero Trust
## 🔍 Definition
A cybersecurity model that assumes no implicit trust — trust is continuously evaluated and access is strictly controlled.

## 🔑 Key Principles
- Never trust, always verify
- Least privilege access
- Microsegmentation
- Continuous authentication and monitoring

## 🔒 Components
- Identity & Access Management (IAM)
- Multi-Factor Authentication (MFA)
- Endpoint Detection & Response (EDR)

## 📌 Real-World Use
- Used heavily in remote access scenarios
- Often implemented via secure access service edge (SASE)
