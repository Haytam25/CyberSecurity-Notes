|Protocol|Purpose|Notes|
|---|---|---|
|**HTTPS**|Secure version of HTTP using TLS/SSL|Encrypts web traffic. Port 443.|
|**FTPS / SFTP**|Secure file transfer|FTPS uses TLS, SFTP uses SSH.|
|**SSH**|Secure Shell for remote access|Replaces Telnet. Port 22.|
|**IPsec**|Secure IP communication (VPNs)|Encrypts and authenticates IP packets. Works in Transport or Tunnel mode.|
|**TLS**|Transport Layer Security|Replaces SSL. Used in HTTPS, email, VoIP, etc.|
|**SNMPv3**|Secure Network Management Protocol|Encrypts data and adds authentication.|
|**SRTP**|Secure Real-Time Transport Protocol|Secures voice/video over IP.|
|**LDAPS**|Secure directory access over SSL/TLS|Port 636.|
