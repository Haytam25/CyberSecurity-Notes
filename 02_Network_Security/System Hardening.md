## ✅ What is System Hardening?

Reducing the attack surface of systems by disabling unnecessary features and securing configurations.

## ✅ Types of Hardening

| Type                      | Techniques                                                                          |
| ------------------------- | ----------------------------------------------------------------------------------- |
| **OS Hardening**          | Disable unused services, patch regularly, enable firewalls, disable guest accounts. |
| **Application Hardening** | Update software, remove unused apps, configure security settings.                   |
| **Network Hardening**     | Use firewalls, disable unused ports/protocols, enforce segmentation.                |
| **Physical Hardening**    | Lock down servers, restrict USB ports, use surveillance.                            |

## ✅ Key Practices

- Remove **bloatware**.
    
- Enable **host-based firewalls**.
    
- Use **group policy (GPO)** for consistent hardening.
    
- Apply **security baselines** (e.g., Microsoft Security Baselines).
    
- Implement **principle of least privilege**.
