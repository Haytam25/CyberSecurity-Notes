## 🔍 Definition
A firewall is a security system that monitors and controls incoming/outgoing network traffic based on rules.

## 🧱 Types
- Network based Firewall (layer 4)
- UTM (all in one security appliance)
- Next-Generation Firewall (NGFW) (layer 7)
- Web Application Firewall (WAF)

## ⚙️ Rule Example
Allow: 192.168.1.10 → TCP Port 80 → Any  
Deny: Any → TCP Port 22 → Internal
## 🗺️ Placement
- Perimeter of network (between LAN and Internet)
- Between segments (e.g. DMZ and internal)

## 🔐 Benefits
- Access control
- Malware blocking
- Logging/monitoring
