# NAT, PAT, and Proxy Servers

## 🔍 NAT (Network Address Translation)
Translates private IP addresses to a public IP before traffic is sent out.

## 🔀 PAT (Port Address Translation)
Also called NAT overload. Uses one public IP with different port numbers.

## 🌐 Proxy Servers
Acts as an intermediary between clients and servers.

### 🔧 Types of Proxy
- Forward Proxy
- Reverse Proxy
- Transparent Proxy

## 🔐 Benefits
- Hides internal IP addresses
- Caching
- Content filtering
- Logging

## 📌 Use Case
- School proxy filtering
- Web application performance enhancement
