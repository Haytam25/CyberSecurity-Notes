## ✅ Common Wireless Threats

- **Evil Twin** – Rogue Wi-Fi access point that mimics a legit one.
    
- **Disassociation Attacks** – Forcing devices to disconnect (DoS).
    
- **Packet Sniffing** – Capturing wireless traffic (e.g., Wireshark).
    
- **Replay Attacks** – Reusing captured authentication packets.
    

## ✅ Wireless Encryption Protocols

| Protocol | Status     | Notes                                                |
| -------- | ---------- | ---------------------------------------------------- |
| **WEP**  | ❌ Obsolete | Weak, crackable in minutes.                          |
| **WPA**  | ❌ Insecure | Temporary fix after WEP, still weak.                 |
| **WPA2** | ✅ Common   | AES-based, uses CCMP. Vulnerable to KRACK.           |
| **WPA3** | ✅ Modern   | Better encryption, protects open networks. Uses SAE. |

## ✅ Wireless Security Best Practices

- Disable **WPS** (Wi-Fi Protected Setup) – easily brute-forced.
    
- Use **strong WPA2/WPA3 passwords** (PSK).
    
- Implement **802.1X** for enterprise-level auth.
    
- Use **MAC filtering** and **SSID hiding** (basic deterrents).
    
- Enable **isolation** between clients on public Wi-Fi.
