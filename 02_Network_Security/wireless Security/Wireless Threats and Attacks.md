# Wireless Threats and Attacks

## Rogue Access Point
- Unauthorized access point added to a network.
- Can allow attackers to bypass security.

## Evil Twin
- A rogue AP that mimics a legitimate one.
- Users unknowingly connect and expose their data.

## Jamming
- Deliberate interference with wireless signals.
- Causes DoS (Denial of Service).

## Disassociation Attack
- Forces clients off a network using deauth frames.
- Can be used to capture handshake data.

## Replay Attacks
- Capturing and retransmitting valid data (e.g., handshakes).
- Can be used for cracking WPA/WPA2 keys.

## Packet Sniffing
- Capturing unencrypted data over open or WEP networks.

## Bluejacking vs Bluesnarfing (Bluetooth)
- **Bluejacking**: Sending unsolicited messages.
- **Bluesnarfing**: Stealing data over Bluetooth.

## Best Practices for Defense
- Use WPA3 or WPA2 with AES.
- Disable WPS (Wi-Fi Protected Setup).
- Use 802.1X with RADIUS for enterprise.
- Monitor for rogue devices.
- Conduct regular wireless audits.
