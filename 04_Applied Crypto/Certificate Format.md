## Common File Extensions
- `.crt` / `.cer` / `.pem`: Contains public certificate (PEM format, Base64).
- `.der`: Binary version of a certificate (used in Java environments).
- `.pfx` / `.p12`: Contains private key and certificate (used for import/export).
- `.key`: Contains only the private key.

## Uses
- Web servers use `.crt`, `.pem`
- Windows systems may use `.pfx` to import certificates.
- Developers use `.key` files for programmatic access.
